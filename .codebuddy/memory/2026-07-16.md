# 2026-07-16

## pgvector + Ollama + Spring AI 2.0 RAG 方案落地

### 架构
- **Chat**: DeepSeek API（OpenAI 兼容协议，`spring.ai.openai` 配置）
- **Embedding**: 本地 Ollama `bge-m3` 模型（1024 维，`spring.ai.ollama` 配置）
- **向量存储**: Spring AI 原生 `PgVectorStore` → PostgreSQL + pgvector 扩展
- DeepSeek 不支持 Embedding API，用 Ollama 本地补位（免费）

### 关键改动
1. **pom.xml**: 新增 `spring-ai-starter-model-ollama` + `spring-ai-starter-vector-store-pgvector`
2. **删除**: 手写的 `PgVectorEmbeddingStore.java`（153 行），改用 Spring AI 原生 `PgVectorStore`
3. **PgVectorConfig**: 手动创建 `@Bean("pgVectorStore")`，用独立 PostgreSQL 数据源（不走 MySQL 主数据源）
4. **application.yml**: 
   - `spring.ai.openai.embedding.enabled: false`（DeepSeek 无 embedding）
   - `spring.ai.ollama.embedding.enabled: true`（model: bge-m3）
   - `spring.ai.ollama.chat.enabled: false`（chat 只用 DeepSeek）
   - `spring.autoconfigure.exclude: PgVectorStoreAutoConfiguration`（避免自动配置冲突）

### 踩坑记录
1. **多 EmbeddingModel 冲突**: OpenAI + Ollama 两个 starter 都创建 `EmbeddingModel` Bean，需用 `@Qualifier("ollamaEmbeddingModel")` 明确指定
2. **多 ChatModel 冲突**: 同理，`AgentEngine` 构造函数需 `@Qualifier("openAiChatModel")` 指定 DeepSeek
3. **PgVectorStoreAutoConfiguration 冲突**: 自动配置也会创建 `VectorStore` Bean，需 `spring.autoconfigure.exclude` 排除
4. **旧表 schema 不兼容**: 旧手写代码建的 `vector_store` 表 `embedding` 列无维度，HNSW 索引报错 "column does not have dimensions"，需 `.removeExistingVectorStoreTable(true)` + `.dimensions(1024)`
5. **spring.ai.*.enabled=false 无效**: Spring AI 2.0 的 `embedding.enabled=false` / `chat.enabled=false` 不能阻止 Bean 创建，必须用 `@Qualifier` 或 `exclude` 解决
6. **根因**: 最开始一直失败是因为 `spring-ai-starter-model-ollama` 依赖被意外丢失，导致 `OllamaEmbeddingModel` Bean 不存在

### 最终文件状态
- `PgVectorConfig.java`: `@Bean("pgVectorStore")` + `@Qualifier("ollamaEmbeddingModel")` + `.removeExistingVectorStoreTable(true)` + `.dimensions(1024)` + `.initializeSchema(true)`
- `AgentEngine.java`: `@Qualifier("openAiChatModel") ChatModel` + `@Qualifier("pgVectorStore") VectorStore`
- `HarnessController.java`: `@Qualifier("pgVectorStore") VectorStore`
- `application.yml`: 排除 `PgVectorStoreAutoConfiguration`，Ollama embedding 开启、chat 关闭，OpenAI embedding 关闭
